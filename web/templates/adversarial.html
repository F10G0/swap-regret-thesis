Environment rule

Punish the historical leader

Before round t, the most frequent action in the selected past window receives payoff 0. Every other action receives payoff 1. Ties rotate deterministically across the tied actions.

The current sampled action is never used to construct its own payoff vector. Bandit learners observe only the sampled payoff; the full vector is retained solely for offline regret evaluation.

Environment rule

Independent lazy reward walks

Each action follows its own precomputed random walk on the grid 0, 0.1, …, 1. Interior rewards move down, stay, or move up with equal probability; boundaries stay or move inward with equal probability.

The complete reward sequence depends only on the environment seed and never on learner actions. The learner seed controls only action sampling.
